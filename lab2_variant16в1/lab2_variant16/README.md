# Програмний проєкт №2 — варіант 16

**Тема:** `adjacent_difference` — пошук максимальної абсолютної різниці між сусідніми елементами.

## Файли проєкту

- `main.cpp` — основний код програми.
- `CMakeLists.txt` — налаштування збирання.
- `data/` — текстові файли з послідовностями.

## Що робить програма

1. Створює три послідовності: 100 000, 500 000 та 1 000 000 чисел.
2. Генерує числа засобами бібліотеки `random` та зберігає їх у текстових файлах.
3. Знаходить максимальну абсолютну різницю між сусідніми елементами.
4. Вимірює час звичайного `adjacent_difference`.
5. Вимірює час роботи з політиками `execution::seq`, `execution::par` та `execution::par_unseq`.
6. Перевіряє власний паралельний алгоритм для різних значень K.
7. Виводить таблицю часу, найкраще K та кількість апаратних потоків процесора.

Для кожного способу вимірювання виконується 5 запусків, після чого виводиться середній час.

## Власний паралельний алгоритм

Послідовність розбивається на K приблизно однакових частин за парами сусідніх елементів. Кожна частина обробляється в окремому потоці за допомогою послідовного `adjacent_difference`. Максимальна різниця в кожній частині знаходиться через `max_element`. Після завершення потоків результати об'єднуються через `max_element`.

## Запуск у Visual Studio

1. Відкрити папку проєкту у Visual Studio.
2. Вибрати конфігурацію `Release`.
3. Зібрати проєкт.
4. Запустити програму з робочою папкою, яка містить папку `data`.
5. Зберегти повний вивід програми у текстовий файл.

Якщо файлів із потрібною кількістю чисел немає або вони неповні, програма створить їх заново.

## Порівняння рівнів оптимізації

Дослідження потрібно виконати у конфігурації `Release` для двох режимів:

- `/Od` — без оптимізації;
- `/O2` — максимальна оптимізація.
